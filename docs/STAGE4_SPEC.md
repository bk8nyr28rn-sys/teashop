# 第四阶段：一门小生意，加工、委托、每天的行情（给 Codex）

> 2026-11-23。先读 `docs/ROADMAP.md` 已定表里「两个口袋」「两个口袋的细则」，和待定表里「经营只有一条直线」那一行；再读 `docs/SESSION_REVIEW.md` 第三节（经营小样）。做完停下来汇报。

## 为什么要做

现在赚钱只有一条直线：出门采东西 → 卖掉 → 换门、装机关。门修满以后，钱就没用了。
这一阶段只加**一小块**，让玩家每天多几个「自己挑」的选择，又不至于东西多到不知道下一步做什么：

1. **加工**：睡前放进灶里，第二天早上就好了，比直接卖更值钱
2. **委托**：邻居托你带东西，给的钱比卖给集市多，还能涨交情
3. **每天的行情**：同一样东西，今天贵、明天便宜

花钱的那一半（扩院子、装饰、给家人买东西）是第五阶段，这次不做。

## 已经定了的规则（照做）

| 规则 | 出处 |
| --- | --- |
| 加工「**过一夜就好**」：睡前开始做，第二天早上（游戏里）就好了，**不另开现实时间的钟** | 路线图待定表「经营」那行；时间只跟着玩家的行动走 |
| 每天行情上下**两成** | 同上 |
| 用谁的东西，钱进谁的口袋：卖自己的进钱袋，卖家里的进钱箱 | 两个口袋的细则 ① |
| 攒天用完时只能看不能动 | 不在线和交给机关的细则 ④ |
| 不在线的日子不算游戏里的天 | 同上 ①；所以不在线时灶里的东西**不会**烧好 |

## 这次的设计

### 1. 加工：院里的灶台

- 院里多一个**灶台**，一次只能烧**一锅**（以后扩院子可以多一个灶，那是第五阶段）。
- 先只有**两样**：

| 放进去 | 第二天早上出来 | 值多少 | 有什么用 |
| --- | --- | --- | --- |
| 3 件柴 | 1 件**木炭** | 14 文（3 件柴原本 9 文） | 卖钱；委托里会要 |
| 2 份草药 | 1 份**金疮药** | 20 文（2 份草药原本 12 文） | 卖钱；疗伤一次回 **2 点**体力（草药回 1 点） |

- **用谁的料，成品就是谁的**：用自己的柴烧出来的木炭是自己的；用家里仓库的柴烧出来的，进家里仓库。
- 什么时候好：放进去以后，**过完这一晚**（亲手守、交给机关都算），第二天早上就能取。只要这一晚还没过完，现实里等多久都不会好。
- 取东西不花时辰，点一下就进对应的口袋或仓库。刷新、两个标签页，都只能取一次。
- 放东西进灶不花时辰；攒天用完时不能放（只能看，灶上写「明天才能生火」）。
- 人走了（老死、早逝），灶里那锅照样烧好，归家里的仓库（细则 ④：家里的东西都留给家）。

### 2. 委托：邻居托你带东西

- 集市里多一块「**邻居托付**」。每天早上最多出现**一条**，来自三户邻居之一，例如：
  > 李二娘：「想要 2 件木炭，给你 40 文。」
- 给的钱大约是**集市基础价的 1.5 倍**（四舍五入成整数），交了以后和那户邻居的**交情 +5**。
- 要的东西从这几样里挑：柴、时蔬、草药、兽皮、木炭、金疮药。数量要是一两天能凑齐的。
- **同时只能接一条**。接了以后 **2 天内**交（游戏里的天）；没交就算了，**不罚钱、不扣交情**，委托消失。
- 交货用谁的东西，钱就进谁的口袋（细则 ①），可以自己的和家里的一起凑。
- 接单时就把价钱定死，之后行情怎么变，这一单都不变。
- 交货不花时辰；攒天用完时不能接、不能交。

### 3. 每天的行情

- 每一天（游戏里的天）开始时，每样普通货定一个当天价：**基础价 × 0.8 到 1.2**，四舍五入，最少 1 文。用这一天的种子定，刷新不重抽。
- **第 1 天固定用基础价**：第一天「卖 7 件柴 + 钱箱 20 文 = 刚好换木门」那条路不能被行情打断。
- 集市里每样货旁边标「今天贵」「今天便宜」或者不标（差不到一成就不标）。院里的预估、集市的单价、一件件卖和全卖，**用的都是同一个价**：一件件卖五次，和一次卖五件，钱一样。
- 宝物不跟行情走，照旧固定价。

### 4. 什么时候开放（接上带路）

| 第几天 | 开放 |
| --- | --- |
| 第 1 天 | 和现在一样；行情固定 |
| 第 2 天 | 行情开始变（集市里出现「今天贵 / 便宜」） |
| 第 3 天 | **灶台**（和家、祠堂、钱箱那句念头同一天；念头一天只说一句，你排一下谁先谁后） |
| 第 4 天 | **邻居托付**（和邻居、交情同一天开放） |

「今天的念头」新加两句，**只在真的能做的时候才说**：
- 灶里的东西好了：「灶上的木炭烧好了，去取吧。」
- 委托凑够了：「李二娘要的木炭，你手上已经够了。」
天快黑时，还是先提醒回家。

## 规则放在哪

- 加工、委托、行情的规则写进 `src/core/loop/`（例如 `economy.ts` 旁边新加 `craft.ts`、`market.ts`），配置放进配置对象，打包进 `assets/loop-core.js`。**规则只写一份**，和第二、三阶段一样。

## 验收

**单元测试**（进 `npm test`）：
- 加工：放料时扣一次料；过完一晚才好，没过完不好（现实日期往后改也不好）；亲手守和交给机关都算过完一晚；取一次只进一次；用自己的料成品归自己，用家里的料成品归家；一次只能烧一锅；人走了那锅归家
- 金疮药回 2 点体力，草药回 1 点；疗伤先用自己的（第二阶段的规则）
- 委托：价钱是基础价的 1.5 倍左右；接单后价钱不变；凑够才能交，交一次只得一次钱和交情；自己的和家里的一起凑时，钱按各自交了几件分别进钱袋和钱箱；2 天没交就消失、不罚；同时只能接一条
- 行情：每样货每天在 0.8–1.2 倍之间；第 1 天等于基础价；同一天刷新不变；一件件卖和全卖总价一样
- 攒天用完时：不能放料、不能接单、不能交货，但能看

**浏览器测试**：
- 第 3 天灶台出现，放 3 件柴，过一晚，第二天早上念头说木炭好了，取出来
- 第 4 天接一条委托，凑够、交货，钱和交情都对
- 第 2 天起集市里有「今天贵 / 便宜」；第 1 天没有，第一天照样能换木门
- 两种屏幕尺寸截图（集市、灶台、委托），没有横向滚动、没有控制台报错

**再加一张表**（只汇报，不用调）：用规则核心模拟几种玩法，每种跑 200 世，看一辈子赚多少钱：只直接卖的、常烧木炭和金疮药的、常接委托的。

**照旧全绿**：`npm run typecheck`、`npm test`、`npm run build:loop -- --check`、`npm run sync:draw -- --check`、`npm run test:proto`、`npm run balance:night -- --compare-core`（守夜难度不改）。
