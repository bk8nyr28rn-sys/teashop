# 小修：不在线守住不给纸钱、第一世的按钮说法（给 Codex）

> 2026-11-23。两处小改，做完停下来汇报。这次的压缩包里 `docs/ROADMAP.md`、`docs/HANDOFF.md` 比你手上的新，先覆盖。

## 1. 不在线时机关守住了，不给纸钱

产品负责人 11-23 定了（`docs/ROADMAP.md` 已定表「不在线和交给机关的细则」⑤）：

- **自己上线、选了「交给机关」守住**：照旧给一半纸钱，进钱袋（现在的做法不变）
- **不在线时机关守住**：**没有纸钱**，只有守住的记录和半份因果

原因：不在线的日子不长年纪、不花攒天，第一世还不丢钱。如果守住还给纸钱，就变成「离开越久，钱袋越鼓」，这正是路线图里说的不做「现实时间的离线收益」。

要改的地方：
- `settleAutoNight` 在 `mode === 'offline'` 时 `earnedMoney` 为 0；战报写「你不在时，机关守住了家门。」，不提纸钱
- 回来时的摘要不出现纸钱
- 「打到一半离开、隔天回来按交给机关守结算」的那一晚算不在线，也没有纸钱

## 2. 第一世「交给机关」按钮的说法

现在第一世写的是「门破了钱箱最多丢 0 文」，读着别扭。改成「第一世有保护，门破了也不丢钱」。第二世起照旧写「门破了钱箱最多丢 X 文」。

## 验收

- 单元测试：不在线守住 `earnedMoney` 为 0、钱袋不变、半份因果照给；主动交给机关守住照旧给一半纸钱；打到一半离开隔天结算的那一晚没有纸钱
- 浏览器测试：改日期离开 3 天，机关守住的日子回来后钱袋不变，摘要里没有纸钱；第一世的按钮写着「第一世有保护，门破了也不丢钱」
- 照旧全绿：`npm run typecheck`、`npm test`、`npm run build:loop -- --check`、`npm run sync:draw -- --check`、`npm run test:proto`、`npm run balance:night -- --compare-core`
