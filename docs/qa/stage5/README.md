## 1. 改了什么

| 文件 | 玩家能看见的变化 |
| --- | --- |
| `src/core/loop/home.ts`（新） | 院子三级（小院 / 中院 120 文 / 大宅 300 文）、装饰四样（盆栽 10、水缸 15、石桌石凳 25、桂花树 40）、匾额 60、摆设（挪、对调、拿掉）。都是家里的东西：先用钱箱，不够再用钱袋 |
| `src/core/loop/trade.ts` | 灶从一口变成「每口灶一项」：小院 1 口、中院 2 口、大宅 3 口，各自过一夜好。第四阶段只有一口灶的旧存档，读进来变成第一口灶 |
| `src/core/loop/family.ts` | 给伴侣买礼物：20 文、红线 +8、只能用钱袋、一天一次 |
| `src/core/loop/household.ts` | 家的存档多了院子等级、摆设、匾额、几口灶；回自家投胎的卡片写着「中院（摆着 3 件东西）」 |
| `docs/proto/loop/index.html`、`prototype/loop.html` | 「修院子」里多了「扩院子」「装饰」两块；院子画面上看得出中院的院墙、大宅的厢房、几口灶、每件装饰、门楣上的「X府」；小按钮「院石」改成「摆设」，能挪院里任何一件东西（院石沿用河埠那一套）；「家和祠堂」里多了「送礼物」 |
| `test/loop/home.test.ts`（新）、`scripts/proto-tests/home.test.cjs`（新） | 8 个单元测试；浏览器里用真按钮走一遍，两种屏幕尺寸 |

没有加新的大按钮，也没有加新的念头去催玩家买装饰。

## 3. 价钱和一辈子赚的钱比一比

整辈子模拟（`npm run sim:life`，样机一辈子 5 天）里，一辈子大约赚 290（宅家）到 660 文（爱冒险）。

| 花在哪 | 全买齐要多少 | 大约是宅家一辈子的几成 |
| --- | ---: | ---: |
| 门（换到机关大门） | 700 | 两辈子多 |
| 机关（4 弩、1 灯、2 符） | 290 | 一辈子 |
| 扩院子（到大宅） | 420 | 一辈子半 |
| 装饰（四样各一件）+ 匾额 | 150 | 半辈子 |

一辈子买不完，要靠好几代人一点点修，这正好是「院子越守越夸张」「家会留下来」：回自家投胎的人，接着上一世修。装饰便宜，一辈子摆几件不难；大宅要攒。
