## 3. 整辈子模拟（任务 3）

`npm run sim:life`，每类 200 世，样机一辈子 5 天。白天走规则核心的野外（机器人会看钟，留够回家的时间），夜里亲手守用每秒 3 下的机器人；宅家的交给机关守。**只汇报，没调数。**

| 玩家 | 守住（亲手 / 机关） | 门破 | 赚的钱 | 野外倒下 | 禁地丢命 | 有后人 | 红线 | 因果分 | 档次（寻常 / 殷实 / 名门） |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- | ---: | --- |
| 爱冒险的（常去禁地） | 4.7 / 0.0 | 0.3 | 659 | 0.0 | 1% | 0% | 没有 | 24.6 | 100% / 0% / 0% |
| 宅家修院子的 | 0.0 / 2.7 | 0.0 | 291 | 0.0 | 0% | 100% | 知己 | 36.3 | 7% / 93% / 0% |
| 爱交朋友的 | 4.0 / 0.0 | 1.0 | 446 | 0.1 | 0% | 100% | 倾心 | 96.6 | 0% / 0% / 100% |
| 只守夜的 | 4.6 / 0.0 | 0.4 | 444 | 0.0 | 0% | 0% | 没有 | 23.0 | 100% / 0% / 0% |

**看到的三件事（要产品负责人判断，没有改）：**

1. **禁地太划算了。** 会看钟的玩家去禁地，几乎不会丢命（1%），钱却赚得最多（659，是宅家的两倍多）。禁地真正危险的地方是「天黑前赶不回来」：同一个机器人不看钟时，禁地丢命是 49%。
2. **不成家，就永远是「寻常人家」。** 因果分的大头是养育（最多 40）和红线（最多 25）。冒险的、只守夜的不成家，一辈子守住再多夜也只有二十几分。这和路线图定的分数上限一致，但玩出来的结果是：想投好人家就必须成家。
3. **交朋友的最省心。** 牵红线、天天陪伴、收徒弟、当护家神，一辈子下来都是名门望族。
