## 3. 几种玩法一辈子赚多少钱

`npm run sim:trade`：白天用规则核心的野外规则真的走一遍（近郊三处加松林，遇险就跑，天黑前回家），第 1 天从河埠搬一根浮木；不算守夜的纸钱。

| 玩法 | 平均（文） | 中间八成 | 比只直接卖 | 平均烧了几锅 | 平均交了几单 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 只直接卖 | 165 | 144–189 | — | 0.0 | 0.0 |
| 常烧木炭和金疮药 | 178 | 154–204 | +8% | 1.7 | 0.0 |
| 常接托付 | 167 | 143–194 | +1% | 0.0 | 0.5 |
| 又烧又接托付 | 181 | 157–207 | +9% | 1.7 | 0.7 |

**看法：**
- 样机一辈子只有 5 天，灶第 3 天才开、托付第 4 天才开，所以**托付几乎来不及做**（平均半单）。正式版一辈子约 11 天，托付能做好几单，差距会拉开。
- 加工多赚一成左右，是「有点值、但不逼你做」的程度，合「每一步都可以不走」。
- **没找到能稳赚的刷法**：游戏里没有「买货」，钱只能从卖货、托付来；灶一次一锅、一天最多一锅；托付一天最多一条，价钱接单时定死。
