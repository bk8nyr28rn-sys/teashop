# 河边一小片：减字（给 Codex 的小任务）

> 2026-11-20。产品负责人确认按「减字」改。
> 在最新的样机上改（河边一小片：`assets/riverside.js`、`assets/riverside.css`，以及 `docs/proto/loop/index.html` 里相关的部分；改完跑 `npm run sync:draw` 同步离线版）。做完停下来汇报。

## 原则：看得见的，就别再写一遍

画面已经能说话了，底下那块大字卡片在抢戏。字只留三种：**人说的话、要做判断的数字、第一次的提示**。

## 1. 点东西：旁边冒小按钮，不弹底部卡片

- 现在：点东西 → 底部弹出一段描述和按钮 → 读完再点
- 改成：点东西 → **东西旁边冒出 1–3 个小按钮**（图标 + 很短的字 + 需要时的数字），例如点木排：「🛶 回家 · 5 分」「✂️ 收排」
- 按钮不能挡住被点的东西；靠近屏幕边时自动往里挪
- 点空地收起按钮
- 东西本身的描述（例如「两根浮木并在一起，麻绳绞紧……」）**删掉**

## 2. 状态用画面表示

| 现在的文字 | 改成 |
| --- | --- |
| 「两手空空 / 周伯搭手」 | 人物头顶或手上的**小图标**（拿着绳子、扛着木头、有人帮忙） |
| 「河水渐涨 / 水漫低岸」 | 画面里**水慢慢漫上来**，被淹的岸边看得出来；只在顶上留一个很小的角标 |
| 顶部的大标题「河埠」和时辰 | 时辰保留（要做判断）；地名缩小，或者只在刚进来时出现一下再淡出 |

## 3. 人说的话：对话气泡

- 路人说的话改成**头顶的气泡**，短句，几秒后淡出
- 只有重要时刻（例如周伯认出你、谢你）才弹卡片，并且卡片里有他的样子

## 4. 第一次的提示，只出现一次

- 例如「沿石板路走，或点一样看中的东西」：第一次进来出现，之后不再出现（记在存档里）
- 第一次碰到某样东西时，可以给一句很短的提示；以后不再出现

## 5. 设置里加「文字说明」开关

- 默认关
- 打开后，点东西时额外显示完整的描述（就是现在那些字），给喜欢读的人和不太会玩游戏的人用

## 验收

- 390 × 844 截图（直接发图片）：点木排时旁边冒出的按钮；扛着木头时人物头上的图标；水漫上来的样子；周伯头上的气泡；打开「文字说明」开关后的样子
- **改前改后对比**：同一个画面，改前一张、改后一张
- 规格里列的搭配全部照常能用；浏览器测试跟着改，全过；`npm test`、`npm run test:proto`、`npm run sync:draw -- --check` 全过
- 汇报里写一下：你自己玩的时候，有没有哪一步因为字少了而**不知道该干嘛**（这种地方要补回一点提示）
