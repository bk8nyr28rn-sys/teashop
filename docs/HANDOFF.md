## 1. 跑起来

需要 Node 22（20 以上应该也行）。

```bash
npm ci               # 装依赖（只有开发依赖：typescript、vitest、tsx、esbuild、@types/node）
npm test             # 旧原型的单元测试，当前 94 个全部通过
npm run typecheck    # 两次类型检查：核心用不含 DOM 和 Node 的配置单独检查
npm run sim          # 旧原型的数值模拟（6 类玩家 × 200 人 × 30 天，约 1 秒）
npm run build:web    # 打包旧原型：dist/web/teashop.html
npm run build:loop   # 把 src/core/loop/browser.ts 打包成 assets/loop-core.js，给样机用（--check 只检查）

# 新方向的样机（需要 Playwright：npm i --no-save playwright && npx playwright install chromium）
npm run test:proto     # 捏人台和一日一夜样机的浏览器测试，截图在系统临时目录的 teashop-proto 下
npm run balance:night  # 守夜难度模拟：不同天数、门、弩机、手速下守不守得住
npm run balance:haunt  # 当厉鬼的难度模拟
npm run balance:loop   # 规则核心的守夜难度（亲手守 + 只靠机关两张表），--json 输出机器可读结果
npm run sim:trade      # 几种玩法一辈子卖货和托付赚多少钱（只汇报）
npm run sim:life       # 整辈子模拟：四类玩家各 200 世，守夜、赚钱、后人、因果分（只汇报）
npm run terms          # 敏感说法在哪些文件里出现几次；换词见 docs/TERMS.md
npm run balance:night -- --compare-core  # 样机和规则核心用同一副牌逐局对账
npm run sync:draw      # 把捏人台的画人代码同步进样机（--check 只检查）
```

样机和捏人台都是单文件页面，直接用浏览器打开就能玩（压缩包里的 `prototype/` 有包好的版本）。样机的「设置」里可以粘贴捏人台的捏人码，也能「快进到最后一天」直接试老死、当鬼和投胎。

### 样机的结构（`docs/proto/loop/index.html`）

一个文件里依次是：样式 → 画人代码（`// @@shared-begin` 到 `// @@shared-end`，从捏人台复制，**不要直接改这段**，改捏人台再跑 `npm run sync:draw`）→ 游戏代码。游戏代码按阶段分块：

| 块 | 主要函数 | 说明 |
| --- | --- | --- |
| 设定 | `CFG`、`RINGS`、`DOORS`、`TRAPS`、`GHOSTS`、`NIGHT`、`PERKS`、`HAUNT`、`GRADES` | 所有数字都在这里 |
| 院子（白天） | `renderHome`、`openMarket`、`openBuild`、`yardOffers`、`openArrange`、`openStove`、`openFriends` | 卖货、修院子（门、机关、扩院子、装饰、匾额）、摆设、灶台、交情。花钱修家的规则在 `src/core/loop/home.ts`，装饰的位置坐标在页面的 `DECOR_SLOTS` |
| 野外（白天） | `renderMap`、`walkTo`、`gather`、`danger`、`knocked`、`dusk`、`goHome` | 三圈地图、天黑前回家 |
| 家 | `offerMatch`、`takeDisciple`、`maybeBirth`、`openFamily`、`openHall`、`ownFamily` | 结缘、孩子、徒弟、祠堂。规则在 `src/core/loop/family.ts`，页面只起名字、画长相 |
| 夜里守门 | `startNight`、`startWave`、`offerPerks`、`choosePerk`、`nightStep`、`hitAt`、`endNight` | 5 波，每波挑本事 |
| 死后 | `die`、`renderDeath`、`startHaunt`、`hauntStep`、`endHaunt` | 护家神 / 厉鬼。当厉鬼的规则在 `src/core/loop/haunt.ts`；开关 `AFTERLIFE.night`（`rebirth.ts`）和设置里的试玩开关能关掉当鬼那一晚 |
| 投胎 | `karmaRows`、`goReborn`、`newFamily`、`reborn` | 因果分、三户人家、回自己家。规则在 `src/core/loop/rebirth.ts` |

状态都在全局 `G`；存进 localStorage 的 `wulin-loop`，现在是 `v: 4`，分成 `account`（账号：攒天、带路、捏的脸）、`person`（这一世的人：钱袋、自己的货、背包）、`houses[houseId]`（每户人家：钱箱、仓库、宝物架、院子、门、机关、画像、守夜回执），字段见 `docs/qa/stage2/README.md`。存档、迁移、两个口袋和夜里结算的规则在 `src/core/loop/`（`economy.ts`、`household.ts`、`settlement.ts`），用 `npm run build:loop` 打包成 `assets/loop-core.js`，**改规则改核心，不要改打包出来的文件**；跨标签写存档用 `assets/loop-storage.js` 的锁。夜里的临时状态在 `N`，当厉鬼时在 `H`。`SPEED` 可以让测试加速。

## 3. 新方向不能破坏的规则

这些是和产品负责人一条条定下来的（细节见 `docs/ROADMAP.md`）。改数字可以，改掉这些行为要先问人。

| 规则 | 为什么 |
| --- | --- |
| 一个现实日 = 一天一夜；白天花的是时辰，**时间只跟着玩家的行动走，不跟现实的钟走**；什么时候守夜由玩家定 | 微信玩家上线时间不一样 |
| 第一版真人之间的互动**大部分异步**：真人厉鬼打你家的机关，结伴借好友的人当电脑帮手。**例外**：族人被砸门可以实时一起打（S0b 先在本地两个标签页做），不在线的族人由电脑操控兜底 | 不用约时间；但一起打最爽，爽度优先（产品负责人 11-28） |
| 鬼大部分是电脑鬼；死去的真人玩家是少见的「厉鬼」精英 | 真人鬼数量不够每家每晚 |
| 不在线（或交给机关守）的晚上：只靠机关守门，**最多丢一点钱，不丢宝物，不伤人**；门破了丢家里钱箱的一成，最多 20 文，离开一段时间最多丢一次 | 产品负责人 11-20 |
| 交给机关守住的晚上算守住一夜，**因果分只给一半** | 亲手守更值 |
| 交给机关守**不让机关真的打一遍**，看家底（门、机关）和当晚鬼的强度算「守住的把握」，开打前告诉玩家 | 光靠机关打几乎每晚都破门，修家就没用了（产品负责人 11-22） |
| 守夜中途**不加**「撑不住了交给机关」的按钮 | 产品负责人 11-22；亲手守和交给机关的差距等真机试玩再看 |
| 不在线的日子不长年纪、不花攒天，守住给半份因果、没守住不扣；整个第一世不在线和交给机关都不丢钱；第 1 晚也能交给机关；攒天用完只能看不能动；交给机关守住的纸钱约为亲手守的一半；**不在线守住没有纸钱**（不做现实时间的离线收益，11-23） | 产品负责人 11-22 逐条定的（`docs/STAGE3_SPEC.md` 的 D1–D5） |
| 白天或守夜打到一半离开：当天回来接着打；隔了一天才回来，那一晚按交给机关守结算 | 产品负责人 11-20 |
| 家里的东西（钱箱、仓库、院子、门、机关、宝物、祠堂）**归家，不归哪一个人**；活着的家人一起用；回自家投胎，钱和货一文不少 | 后人是真人，你老死时他们可能还活着 |
| 两个口袋：家里的钱箱**只能花在家上**；自己的钱袋装自己挣的钱，买自己的东西；老死时钱袋进钱箱。细则：背回来的东西归自己，放进仓库才归家；亲手守门破了，钱袋随机丢两到四成、钱箱零到两成（开打前定好，刷新不重抽）；花完东西留在家里的钱箱钱袋都能用，到了个人手里的只能用钱袋 | 孩子是陌生人投胎来的，不能让一个人掏空全家 |
| 没有后人时宅子不消失（长草、门变旧），东西和画像都在 | 家会留下来 |
| 回自家投胎的第一天，祖传的机关照常工作；带路只藏「买」的入口 | 已有的东西不能不管用 |
| 人会老死，家会留下来：院子、祠堂、做过的东西跨世保留 | 产品负责人 11-20 |
| 鬼头上**只写特点（飞、隐、甲），不写该用什么**；每个特点至少有三种解法 | 自由度：方法放开 |
| 鬼跟着工具一起来：手里只有剑的晚上只来普通鬼 | 新玩家第一晚要守得住（产品负责人 11-21） |
| 老死后「当一晚鬼」做成开关（`AFTERLIFE.night`），敏感的词集中在 `docs/TERMS.md`，能一键换（`scripts/terms.mjs`）。加新文字时尽量用表里已有的说法 | 万一审核不让写阴间，改开关、换词就行，不用改玩法（产品负责人 11-24） |
| 和人说话：用 `talkHead(npc, line)` 画头像和一句话，回话放进 `sheet` 的按钮（class `reply`）。台词看情况变（`merchantLine`、`ancestorNightLine`、`neighborTalk`），一句话以内。已做七处：天黑的祖宗、集市钱掌柜、邻居上门、修院子鲁师傅（`carpenterLine`）、家和祠堂伴侣或祖宗（`familyTalk`）、回来时的摘要祖宗（`assets/house-watch.js`）、奈何桥摆渡人（`ferrymanLine`）。数字照旧写在小字里 | 产品负责人 11-24：让游玩感觉更像和人打交道 |

## 4. 难度现状（样机，`npm run balance:night`）

机器人按「人手速度」点鬼（每秒 3 或 4 下），会按特点换东西，本事随机挑。机器人每一下都打得准，真人会更难。

| 情况 | 结果（6 局） |
| --- | --- |
| 第 1 天，柴门，没机关 | 带路首夜锁剑，五波普通鬼为 3、4、6、7、9 只。核心固定种子每档 200 局：每秒 1.5、2、3、4 下分别守住 180、198、200、200 局，胜局平均门血为 91.5%、96.5%、100%、100%。只给原五波合计加 0–32 只普通鬼，排查 435,897 种固定分配后，满足两档守住率下限的方案在 2 下/秒时平均门血最低仍为 96.5%；例如只把第三波加到 11 只可降到 84.2%，但 1.5 下/秒只守住 124/200，无法兼顾原定的 70%–90% 门血和新手胜率。优先让新手守住。样机原生抽签的 1.5 下/秒为 179/200，2 下/秒为 198/200、胜局门血 96.1%；真人的门血留待真机试玩再看。全开放首夜 3 下/秒仍全守住。 |
| 第 3 天，柴门，每秒 3 下 | 大多守住，门剩七成多 |
| 第 5 天，柴门 | 基本守不住 |
| 第 5 天，铁皮门 + 2 台弩机 | 每秒 3 下一半守住；每秒 4 下大多守住 |
| 第 5 天，朱漆铜钉门 + 3 台弩机 | 大多守住 |
| 第 1 天只拿剑、不换东西（全开放） | 每秒 4 下守住 3 成：挑对本事能补短板 |

当厉鬼（`npm run balance:haunt`）：门档 1 很容易，门档 2 要手快，门档 3 很难；红光期间按躲就一定躲得开（之前躲闪比预警短，按了也会被射中，改掉了）。

调难度的经验：一晚 5 波、本事会让玩家越打越强，所以前几波要挤（`NIGHT.spread`），后面靠鬼的数量和血量涨。改完一定跑 `balance:night`，只看一两个格子容易调出悬崖。

## 5. 旧原型（`src/`）的规则和经验

第二期搬规则时，下面这些底子要保留；和新方向冲突的以新方向为准（例如「道途」已经去掉）。

- 规则代码必须**确定性**：所有随机走 `world.rng`，不能用 `Math.random` 或 `Date`（存档测试会查）
- 拉黑：零代价、即时、不可逆；**不在线本身不算冷落**
- 离线期间最多被砸破一次
- 任何「亏了再赚回来还多一点」的机制都会被刷（吵架刷浓度、剪线复合刷浓度都出现过）：怨丝变回情丝的比例必须小于 1:1
- 调一个数会连锁影响别处，每次改完跑全套模拟
- 给追赶机制加门槛，往往正好挡住最需要它的人
- 界面层只调用 `src/core/index.ts` 导出的函数，规则通过 `world.listener` 发事件；**不要在界面层写规则**
- 旧原型的按钮按「按下时记住、松手时还在同一个按钮上才算点到」来认（`src/web/ui.ts` 的 `bind`），这是为了修 Mac 触控板上点了没反应的问题，不要改回只用 `click`
