## 1. 跑起来

需要 Node 22（20 以上应该也行）。

```bash
npm ci               # 装依赖（只有开发依赖：typescript、vitest、tsx、esbuild、@types/node）
npm test             # 旧原型的单元测试，当前 94 个全部通过
npm run typecheck    # 两次类型检查：核心用不含 DOM 和 Node 的配置单独检查
npm run sim          # 旧原型的数值模拟（6 类玩家 × 200 人 × 30 天，约 1 秒）
npm run build:web    # 打包旧原型：dist/web/teashop.html

# 新方向的样机（需要 Playwright：npm i --no-save playwright && npx playwright install chromium）
npm run test:proto     # 捏人台和一日一夜样机的浏览器测试，截图在系统临时目录的 teashop-proto 下
npm run balance:night  # 守夜难度模拟：不同天数、门、弩机、手速下守不守得住
npm run balance:haunt  # 当厉鬼的难度模拟
npm run sync:draw      # 把捏人台的画人代码同步进样机（--check 只检查）
```

样机和捏人台都是单文件页面，直接用浏览器打开就能玩（压缩包里的 `prototype/` 有包好的版本）。样机的「设置」里可以粘贴捏人台的捏人码，也能「快进到最后一天」直接试老死、当鬼和投胎。

### 样机的结构（`docs/proto/loop/index.html`）

一个文件里依次是：样式 → 画人代码（`// @@shared-begin` 到 `// @@shared-end`，从捏人台复制，**不要直接改这段**，改捏人台再跑 `npm run sync:draw`）→ 游戏代码。游戏代码按阶段分块：

| 块 | 主要函数 | 说明 |
| --- | --- | --- |
| 设定 | `CFG`、`RINGS`、`DOORS`、`TRAPS`、`GHOSTS`、`NIGHT`、`PERKS`、`HAUNT`、`GRADES` | 所有数字都在这里 |
| 院子（白天） | `renderHome`、`openMarket`、`openBuild`、`openFriends` | 卖货、修院子、交情 |
| 野外（白天） | `renderMap`、`walkTo`、`gather`、`danger`、`knocked`、`dusk`、`goHome` | 三圈地图、天黑前回家 |
| 家 | `offerMatch`、`takeDisciple`、`maybeBirth`、`openFamily`、`openHall`、`ownFamily` | 结缘、孩子、徒弟、祠堂 |
| 夜里守门 | `startNight`、`startWave`、`offerPerks`、`choosePerk`、`nightStep`、`hitAt`、`endNight` | 5 波，每波挑本事 |
| 死后 | `die`、`renderDeath`、`startHaunt`、`hauntStep`、`endHaunt` | 护家神 / 厉鬼 |
| 投胎 | `karmaRows`、`goReborn`、`newFamily`、`reborn` | 因果分、三户人家、回自己家 |

状态都在全局 `G`（存进 localStorage 的 `wulin-loop`，版本 `v: 2`）；夜里的临时状态在 `N`，当厉鬼时在 `H`。`SPEED` 可以让测试加速。

## 3. 新方向不能破坏的规则

这些是和产品负责人一条条定下来的（细节见 `docs/ROADMAP.md`）。改数字可以，改掉这些行为要先问人。

| 规则 | 为什么 |
| --- | --- |
| 一个现实日 = 一天一夜；白天花的是时辰，**时间只跟着玩家的行动走，不跟现实的钟走**；什么时候守夜由玩家定 | 微信玩家上线时间不一样 |
| 第一版真人之间的互动**全部异步**：真人厉鬼打你家的机关，结伴和驰援借好友的人当电脑帮手 | 不用约时间；服务器简单 |
| 鬼大部分是电脑鬼；死去的真人玩家是少见的「厉鬼」精英 | 真人鬼数量不够每家每晚 |
| 不在线（或交给机关守）的晚上：只靠机关守门，**最多丢一点钱，不丢宝物，不伤人**；门破了丢家里钱箱的一成，最多 20 文，离开一段时间最多丢一次 | 产品负责人 11-20 |
| 交给机关守住的晚上算守住一夜，**因果分只给一半** | 亲手守更值 |
| 白天或守夜打到一半离开：当天回来接着打；隔了一天才回来，那一晚按交给机关守结算 | 产品负责人 11-20 |
| 家里的东西（钱箱、仓库、院子、门、机关、宝物、祠堂）**归家，不归哪一个人**；活着的家人一起用；回自家投胎，钱和货一文不少 | 后人是真人，你老死时他们可能还活着 |
| 两个口袋：家里的钱箱**只能花在家上**；自己的钱袋装自己挣的钱，买自己的东西；老死时钱袋进钱箱 | 孩子是陌生人投胎来的，不能让一个人掏空全家 |
| 没有后人时宅子不消失（长草、门变旧），东西和画像都在 | 家会留下来 |
| 回自家投胎的第一天，祖传的机关照常工作；带路只藏「买」的入口 | 已有的东西不能不管用 |
| 人会老死，家会留下来：院子、祠堂、做过的东西跨世保留 | 产品负责人 11-20 |
| 鬼头上**只写特点（飞、隐、甲），不写该用什么**；每个特点至少有三种解法 | 自由度：方法放开 |
| 没有职业。打法看手里的东西（随时换）和当晚挑的本事 | 自由度 |
| 出生品级之间的**强弱最多差三成**（×1 到 ×1.3），品级主要给面子 | 孩子是别人投胎来的新玩家，不能让陌生人的感情决定他弱好几倍 |
| 有后人有两条路：牵红线生孩子，或者收徒弟 | 不想谈恋爱也能有后人；任何性别组合都行 |
| 有后人就能投胎回自己家，院子、机关、宝物都在，祠堂里挂着前几世的你 | 传承是核心情感 |
| 在野外倒下：东西掉在原地、人重伤；**只有一个人倒在禁地才可能丢命** | 一辈子只有 1–2 周，随便死太狠 |
| 卖外观可以；**永远不卖**门血、红线、孩子数值、因果分，也**不卖时间** | 公平；卖时间会毁掉「天黑前回家」 |
| 人物形象里不放戏曲元素 | 产品负责人 11-15 |
| 未成年保护：只做时段限制 + 法律硬性要求（实名、付费限制）；另外两条建议**待产品负责人决定**，先别实现 | 待定 |

## 4. 难度现状（样机，`npm run balance:night`）

机器人按「人手速度」点鬼（每秒 3 或 4 下），会按特点换东西，本事随机挑。机器人每一下都打得准，真人会更难。

| 情况 | 结果（6 局） |
| --- | --- |
| 第 1 天，柴门，没机关 | 全守住，门掉一点血（新手教学） |
| 第 3 天，柴门，每秒 3 下 | 大多守住，门剩七成多 |
| 第 5 天，柴门 | 基本守不住 |
| 第 5 天，铁皮门 + 2 台弩机 | 每秒 3 下一半守住；每秒 4 下大多守住 |
| 第 5 天，朱漆铜钉门 + 3 台弩机 | 大多守住 |
| 第 1 天只拿剑、不换东西 | 能赢一半：挑对本事能补短板（这是想要的） |

当厉鬼（`npm run balance:haunt`）：门档 1 很容易，门档 2 要手快，门档 3 很难；红光期间按躲就一定躲得开（之前躲闪比预警短，按了也会被射中，改掉了）。

调难度的经验：一晚 5 波、本事会让玩家越打越强，所以前几波要挤（`NIGHT.spread`），后面靠鬼的数量和血量涨。改完一定跑 `balance:night`，只看一两个格子容易调出悬崖。

## 5. 旧原型（`src/`）的规则和经验

第二期搬规则时，下面这些底子要保留；和新方向冲突的以新方向为准（例如「道途」已经去掉）。

- 规则代码必须**确定性**：所有随机走 `world.rng`，不能用 `Math.random` 或 `Date`（存档测试会查）
- 拉黑：零代价、即时、不可逆；**不在线本身不算冷落**
- 离线期间最多被砸破一次
- 任何「亏了再赚回来还多一点」的机制都会被刷（吵架刷浓度、剪线复合刷浓度都出现过）：怨丝变回情丝的比例必须小于 1:1
- 调一个数会连锁影响别处，每次改完跑全套模拟
- 给追赶机制加门槛，往往正好挡住最需要它的人
- 界面层只调用 `src/core/index.ts` 导出的函数，规则通过 `world.listener` 发事件；**不要在界面层写规则**
- 旧原型的按钮按「按下时记住、松手时还在同一个按钮上才算点到」来认（`src/web/ui.ts` 的 `bind`），这是为了修 Mac 触控板上点了没反应的问题，不要改回只用 `click`

旧原型的数值校准目标（金缕约 90 天、砸破每周 0.4–0.9 次等）在 Git 历史里这份文件的旧版本中；新方向的数字要重新用模拟器定。

## 6. 已知问题

| 项目 | 说明 |
| --- | --- |
| 规则还在页面里 | 样机的规则写在 HTML 的脚本里，没有单元测试，只有浏览器测试；要搬进 `src/core/loop/`（正在做第一阶段） |
| 一晚能扣两次 | 门破了以后，在结算页刷新，这一晚会重打一遍，钱和宝物再扣一次（`docs/SESSION_REVIEW.md` 第一节）。第一阶段任务里先在样机里补上 |
| 回自家投胎丢东西 | 只带回六成的钱，仓库清空；和「钱和货一文不少」不符。第一阶段任务里先在样机里补上 |
| 门口图标会叠 | 鬼挤在门口时，头上的图标和血条叠在一起 |
| 后人选不了 | 有好几个后人时，投胎默认去第一个后人家，玩家不能挑 |
| 当厉鬼太浅 | 只有「点」和「躲」 |
| 野外地图 | 还是平涂的圈，没有雾 |
| 声音 | 没有；捏人台里的浏览器朗读只是占位 |
| 画人 | 捏人台和样机用 SVG 画人；正式版在 Cocos 里要重写渲染，只有参数和规则能直接搬 |
| 服务器 | 没有；第一版打算用微信云开发（因为真人互动全是异步） |

## 7. 改完怎么验证

1. `npm run typecheck && npm test` 全绿
2. 动了样机或捏人台：`npm run test:proto` 全绿；动了守夜或当厉鬼的数字：再跑 `balance:night` / `balance:haunt`，和第 4 节对比
3. 动了捏人台的画人代码：`npm run sync:draw`，再跑 `test:proto`
4. 动了界面：用 390 × 844 和 320 × 640 两种尺寸看一眼，没有横向滚动、没有控制台报错
5. 新规则进 `src/core` 必须配单元测试；随机只能走注入的随机数

在线版本（只有产品负责人的账号能打开）：路线图文档、捏人台、一日一夜样机。离线副本都在压缩包里。
