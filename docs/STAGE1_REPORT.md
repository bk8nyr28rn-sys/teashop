## 4. 样机问题、路线图衔接与待定事项

- **首夜教学的两种胜率差别很大。** 交接说明里的“首夜全守住”使用全部开放、会换弓和灯的机器人。真实带路首夜锁剑，每秒 4 下，样机和核心各胜 11/40；每秒 2 下分别为 5/40、4/40。向第一次玩的玩家描述难度时，应看带路这一行。
- **样机随机排序受浏览器实现影响。** 样机用随机比较器抽波次顺序和本事，浮字等外观也会消耗随机数。迁移时试过均匀洗牌，双弩铁皮门一格的胜局由样机 23/40 变成 15/40。交付版固定短牌池的插入抽签步骤，保留原有偏重，玩法与外观分别用种子；攻击、门血、掉落等参数沿用样机。
- **野外掉落原先只有提示。** 样机会清空背包，画面说“掉在原地”，地点里没有掉落记录。核心按路线图把物件存到原地点，离线 JSON 读回后仍在。跨玩家访问在后续共享世界实现。走路恰好 18:00 到野外会遇鬼，恰好 18:00 进院则成功；采集或爬回可把时刻推过 18:00。迁移保留上述边界。
- **新版路线图和现网页有阶段差异。** 样机尚未打完时刷新会重打，跨现实日也沿用当前样机入口；核心已经能从半夜快照续跑。无后人老宅的跨世保存仍待家档阶段，当前页面仍提示院子荒掉。已完成结算的回执保护适用于新版写出的结果；旧版已经二次扣掉且没有回执的数据，无法仅凭余额还原。
- **两口袋细则仍需在阶段 2 前决定。** 请确定背回家的货卖出后钱进哪里、亲守破门时哪些钱暴露给鬼、家人花销用哪个口袋。核心可以分别保存钱箱和钱袋，亲守默认以传入的家产钱箱快照对照旧样机，可显式传入旧单一钱堆基数 `lossBase`；只返回三成损失额，不执行转账。阶段 3 前还要用亲守与代守的实际损失一起试玩，确认玩家是否愿意自己守难夜。
