## 为什么要做

第四阶段让钱多了几种来路（加工、托付、行情），可是钱的去处还是只有门和机关。门修满、机关装满以后，钱就没用了。
这一阶段让钱有**四个去处**，每个去处换来的东西都不一样，玩家自己挑：

| 花在哪 | 换来什么 | 谁会喜欢 |
| --- | --- | --- |
| 🚪 门和机关（已有） | **安全**：亲手守更稳，交给机关的把握更高 | 怕丢东西的 |
| 🏡 扩院子（新） | **能多做事**：多一口灶，多几个摆东西的位置 | 爱经营的 |
| 🌳 装饰（新） | **面子**：院子越来越好看，传给下一世 | 爱布置的 |
| 💝 家人（新） | **红线**：红线越浓，孩子品级越好 | 重感情的 |

没有哪个是「最划算」的，换来的东西各不相同，这就是自由度。

## 1. 扩院子

| 院子 | 花多少 | 多了什么 |
| --- | --- | --- |
| 小院（开局） | — | 1 口灶，3 个摆东西的位置 |
| 中院 | 120 文 | **第 2 口灶**，5 个位置，院墙加长 |
| 大宅 | 300 文 | **第 3 口灶**，7 个位置，加一进厢房 |

- 是家里的东西：先用钱箱，不够再用钱袋（细则 ③）
- 跟着家走，下一世回自家还在（「家会留下来」）
- 画面上看得出来：院墙变宽，大宅多一间厢房

## 2. 装饰

在「修院子」里买，买了摆在院子的空位上，**摆在哪你自己挑**，以后随时能挪。

| 装饰 | 花多少 | 样子 |
| --- | --- | --- |
| 盆栽 | 10 文 | 一盆小松 |
| 水缸 | 15 文 | 养着两尾鱼 |
| 石桌石凳 | 25 文 | 夏天能在院里吃饭 |
| 桂花树 | 40 文 | 会开花，秋天满院香 |
| 匾额 | 60 文 | 门楣上挂着家名，例如「林府」 |
| 院石（已有） | 河埠搬回来 | 和现在一样 |

- **只给面子，不加战力**：不让「装饰越多越能打」，免得变成必须买
- 家里的东西：先用钱箱，不够再用钱袋
- 跟着家走，下一世回自家还摆在原处；奈何桥选人家时，回自家那张卡写着「院里摆着 4 件东西」
- 位置不够了就要扩院子：这是扩院子的另一个理由

## 3. 家人

- **给伴侣买礼物**：20 文，红线 +8，一天一次
- 和「陪伴」比：陪伴花 1 个时辰（白天少出一趟门），红线 +12；礼物花钱不花时间。**有钱的花钱，有时间的花时间**，玩家自己挑
- 礼物到了某个人手里，**只能用钱袋**（细则 ③）
- 收徒弟（已有，30 文）不变
- 孩子在正式版是真人玩家，给孩子送东西等多人版再做

## 4. 放在哪、什么时候出现

- 扩院子和装饰都放进「修院子」，**不加新的大按钮**（院子已经只留 4 个大按钮）。「修院子」里分三块：门和机关、扩院子、装饰
- 摆东西：现在的小按钮「院石」改名「摆设」，能挪院子里任何一件装饰
- 给伴侣买礼物：放在「家和祠堂」里，和「陪伴」并排
- 第 2 天起，「修院子」里看得到装饰和扩院子（和机关同一天）；礼物要有伴侣才有
- **不加新的念头**：装饰不是非做不可，不去催玩家

## 5. 验收

- 规则写进 `src/core/loop/`（例如 `home.ts`），打包进 `assets/loop-core.js`，规则只写一份
- 单元测试：扩院子先扣钱箱再扣钱袋、钱不够不能买、不能跳级；中院、大宅灶的口数对；装饰只能摆在空位、能挪、位置数跟院子等级走；礼物只能用钱袋、一天一次、红线最多到 100；扩院子、装饰跟着家走，回自家投胎都在
- 浏览器测试：买一件装饰摆上、挪个位置、刷新还在；扩成中院，能同时烧两锅；送礼物红线涨；两种屏幕尺寸不出横向滚动
- 照旧全绿：`npm run typecheck`、`npm test`、`npm run build:loop -- --check`、`npm run sync:draw -- --check`、`npm run test:proto`
- 模拟：在第四阶段的「一辈子赚多少钱」上，再看钱都花到了哪四个地方

## 6. 这次不做

- 自己画的装饰、匾额上的字自己写（点子池：「一切都能自己画」）
- 给孩子送东西（等多人版）
- 别人路过能看到你家院子（等服务器）
