# 带路 · 念头表

玩家随时可以换个主意。念头只读眼前的情况，点开能看到一句缘由。照着做完时，顶栏会短暂回一句话。奖励、扣天和战斗结算都沿用原玩法。

| 念头 | 什么时候出现 | 怎么算做完 |
| --- | --- | --- |
| 推开院门，过第一天／等天亮，再过一天 | 初次开局、守夜结算后，或转世等开天 | 点开始进入白天。初次捏完人进入院子也算 |
| 去河埠走走 | 第一天在院里，还没去过河埠 | 第一次走进河埠 |
| 看看岸边有什么拿得动 | 在河埠，手里和背包里都没有要带回家的东西 | 搬起木头或院石、拿绳或采到药 |
| 带着绳去看看挑担人 | 腰上有绳，周伯的筐还卡着，手里没有要带走的东西 | 把绳递过去，帮周伯拉出筐 |
| 把东西带回院子 | 河埠手里有重物、包里有东西，或在大地图上背着收获且没有另选目的地 | 东西随人进院，重物和背包按原规则安放、入库或上架 |
| 天快黑了，回家吧 | 人在河埠或大地图，离天黑不足一个时辰。天黑后文字会改为催归 | 回到院内，空手也算 |
| 拿一件存货去集市卖 | 在家有普通存货，今天还没卖过普通货物 | 单卖一件、卖光一种或整仓出售 |
| 换扇结实的木门 | 在家还是柴门，身上至少有 40 文 | 在「修院子」里买下木门 |
| 用仓里的草药敷一下伤 | 在家体力未满，仓里有草药 | 用一份草药疗伤 |
| 挑个想去的地方，看看线索 | 大地图已开放，今天还没进过地图，或站在地图中心还没选地点 | 点中地名，看到当天的线索 |
| 去看看线索指的地方／照着眼前的线索找一次 | 选好目的地，或已经站在当地准备采集 | 到地方后实际找一次，稳妥找或冒险找都可以 |
| 回家看看祠堂里的画像 | 第三天起，在院里，这一世还没看过画像 | 通过「家和祠堂」进入祠堂 |
| 回屋歇脚，等天黑守门 | 在院里接近天黑，或今天已经逛过、暂时没有更迫切的事 | 从院里进入守夜 |
| 守住自家的门 | 夜里守门，或当护家神守夜 | 门撑过最后一波。门破了也照常进入结算 |
| 给下一世选个去处 | 这一世结束、当厉鬼或到了奈何桥 | 选好投胎的人家，开始新一世 |

同一时间只显示一条。在外面优先看天色，再看手里带着什么。在家已经天黑就去守门，白天则先看伤势、换门的钱和仓里的货，再轮到探亲或出门。玩家可以直接去做别的事。
