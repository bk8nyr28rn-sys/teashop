# 画人台：什么都能自己画（给 Codex 的规格）

> 2026-11-18，产品负责人的要求：**表情、头发、衣服、饰品，什么都可以自己画；画的入口要一眼看得到。** 现成的款式可以留着，但只是起点，不能是限制。
> 在 Codex 手里最新的捏人台上改（已经接进游戏的那一版）。做完停下来汇报。

## 现在的问题

- 手绘在分页栏最右边，手机上要往左滑才看得到，产品负责人根本没找到
- 只能画脸上、4 个手绘表情、衣服花纹、胸前图案；**头发、衣服、饰品的形状都画不了**

## 1. 入口一眼可见

- 「手绘」分页挪到第二个（紧跟「身体」），手机上不用滑就能看到
- 头发、服装、配饰、表情、五官这几个分页，**最上面都放一个醒目的「✏️ 自己画」按钮**，点了直接打开对应部位的画布（例如在头发页就是画头发）
- 第一次打开捏人台时，出一句提示：「什么都可以自己画，点 ✏️」

## 2. 人体模型

- 加一个选项「从光身小人开始」：一键去掉所有现成部件，只剩基础身体（比例、肤色照常能调）和一套最简单的五官
- 每个部位都有开关「用现成款 / 只用我画的」：画了头发，就能把现成的头发关掉

## 3. 按部位分层画（画在哪块，就跟着哪块动）

| 画布 | 跟着什么动 |
| --- | --- |
| 前发、后发、头饰 | 头 |
| 脸（一直显示）、手绘表情 | 头 |
| 上衣、背后（披风、兵器） | 身体 |
| 袖子（画一边，另一边自动镜像） | 手臂 |
| 下装、鞋 | 腿 |

- 每块画布上淡淡显示人体轮廓当参照
- 童年、老年、当鬼（发白）、祠堂画像里，画的东西都跟着用
- 样机现在只有一个站姿，但每层要记下它挂在哪个部位上，以后在 Cocos 里绑到骨骼上，走路、出手时才能跟着动

## 4. 表情

- 现成的表情都留着，每个都能「改画」：把这个表情复制成底稿，在上面改
- 手绘表情从 4 个加到 8 个；在游戏的表情栏里和现成表情放在一起

## 5. 工具（不会画画的人也能画好看）

- 画笔（几档粗细）、橡皮、调色盘
- **油漆桶**：先画轮廓，再一键填色
- **左右对称**：画一边，另一边自动出来
- 撤销、重做
- 图形贴片：圆、方、直线、波浪
- **底稿**：选一个现成款当淡色底稿来描或者在上面改

技术建议：油漆桶和橡皮用位图好做，可以把每层改成按部位的位图画布（例如 256 × 256），以后在 Cocos 里直接当贴图。捏人码会变长，样机阶段可以接受；要控制一个人所有画布加起来的大小，汇报里写一下实际大小。

## 6. 验收

- 390 × 844 下截图：每个分页顶上都能看到「✏️ 自己画」；手绘分页不用滑就能看到
- 从光身小人开始，自己画头发和衣服，关掉现成款，保存回游戏：院子、守夜、当鬼、祠堂画像里都是画的样子
- 改画一个现成表情，在游戏表情栏里能用
- 油漆桶、左右对称、撤销能用
- 手机上同时画 10 个带手绘的人物不卡（写一下实际帧数）
- `npm test`、`npm run test:proto`、`npm run sync:draw -- --check` 全过
