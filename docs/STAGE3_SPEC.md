# 第三阶段：交给机关守、不在线的晚上、回来时的摘要（给 Codex）

> 2026-11-22。先读 `docs/ROADMAP.md` 已定表里「不在线时」「守夜不是通行证」「交给机关守的晚上」「交给机关守怎么算」「打到一半离开」这几行，再读 `docs/SESSION_REVIEW.md` 第二节和最后那张表的第 3 行。做完停下来汇报。

## 这次要做成什么

1. 玩家不想自己打的晚上，可以**交给机关守**，开打前就知道守住的把握有多大
2. 玩家不在线的日子，家里照样会被砸门，机关按同样的办法守
3. 玩家回来时，先告诉他**离开以后家里发生了什么**

## 产品负责人定好的规则

| 规则 | 说明 |
| --- | --- |
| 看家底算把握（11-22） | **不让机关真的打一遍。** 每晚的鬼有一个强度，天数越往后越强；家里有一个防守分，门越好、机关越多，分越高。两个一比，算出「守住的把握」。开打前告诉玩家 |
| 门破了丢多少（11-20） | 交给机关守和不在线一样：只丢**钱箱的一成，最多 20 文**；不碰钱袋，不丢宝物，不伤人 |
| 守住了算什么（11-20） | 交给机关守住，算守住一夜，**因果分只给一半** |
| 打到一半离开（11-20） | 白天或守夜打到一半离开：当天回来就接着打；隔了一天才回来，那一晚按交给机关守结算 |
| 不加中途按钮（11-22） | 守夜打到一半**不加**「撑不住了交给机关」的按钮。亲手守和交给机关的差距，等真机试玩再看 |

## 细则（产品负责人 11-22 一条条定的）

| # | 规则 |
| --- | --- |
| D1 | **不在线的日子**：每个没上线的现实日，家里被砸一次门（家宅来袭），按把握算。**连着没来的几天，最多丢一次钱。** 这些不算游戏里的天：**不长年纪、不花攒天**。机关守住了**给半份因果**（和交给机关守一样），没守住**不扣**因果分 |
| D2 | **整个第一世都有保护**：第一世里，不在线和交给机关守都**不丢钱**（门照样会被砸破，战报照样写，例如「机关没守住，好在新家有保护，没丢东西」）。第二世起照常 |
| D3 | **第 1 晚也能交给机关**：带路的第 1 晚两个选择都有，一模一样，不劝玩家选哪个 |
| D4 | **攒天用完时只能看，不能动**：能看战报、回来时的摘要、家人和祠堂、院子；**不能买卖、不能修院子、不能存钱**，出门和过夜也不行。这些按钮灰掉，写一句「明天才能……」 |
| D5 | **交给机关守住也有纸钱，大约是亲手守的一半**，进守夜人的钱袋。本事是亲手守时才用得上的，机关守的晚上没有 |

## 要做什么

### 1. 把握怎么算

- 写在规则核心里（`src/core/loop/`），页面通过 `assets/loop-core.js` 用，规则只写一份。
- 输入：当晚的天数、门（门血）、弩机数量、灯笼串、镇宅符。输出：守住的把握（0 到 1）。公式你定，数字放进配置里。
- 下面是**大概的目标**，用来调公式，不用卡得很死：

| 情况 | 把握大约 |
| --- | --- |
| 第 1 天，柴门，没机关 | 3 成 |
| 第 3 天，木门 + 1 台弩机 | 5 成 |
| 第 5 天，铁皮门 + 2 台弩机 + 灯笼串 | 6 成 |
| 第 5 天，朱漆铜钉门 + 3 台弩机 + 灯笼串 + 镇宅符 | 8–9 成 |

- 最高 95%（修得再好也留一点悬念），最低 5%。
- 门越好、机关越多，把握一定更高；天数越往后，把握一定更低。
- 显示时说成「X 成」，不显示小数。

### 2. 交给机关守（玩家自己选）

- 天黑要守夜时（歇到天黑、从野外回到家、遇暮折返），给两个选择：**亲手守** / **交给机关**，交给机关那个按钮上写把握和最多丢多少，例如：「交给机关 · 守住的把握七成 · 门破了最多丢 20 文」。
- 结果在这一晚开始时就用这一晚的种子定好，存进第二阶段的那套夜账里。刷新、两个标签页都只结算一次，结果不变。
- 交给机关和亲手守一样，算过了这一夜：第二天早上照常花一天攒天。
- 战报一句话说清楚：「机关守住了，门还剩六成。」或者「机关没守住，钱箱少了 8 文。」
- **修院子时显示把握的变化**：换门、装机关的按钮上写「交给机关守的把握：五成 → 六成」。花钱修家，玩家马上看得见效果。

### 3. 不在线的晚上

- 玩家回来时（开页、从后台切回来），先算离开期间没来的现实日（按 D1），用同一个把握函数结算，钱照「最多丢一次、最多 20 文」扣在钱箱上。
- 和交给机关守用**同一个结算函数**，只是战报的说法不同。
- 「今天是哪一天」由页面传给核心，核心里不读现实的钟（和攒天一样）。
- 「打到一半离开」：当天回来接着打（现在已经是这样）；隔了一天才回来，那一晚按交给机关守结算，把握按家底算。

### 4. 回来时的摘要

- 有事时，进来先看到一张小卡片，只写真的发生了的事，例如：
  - 「你不在的 2 天里，鬼来砸了 2 次门：机关守住 1 次，没守住 1 次，钱箱少了 12 文。」
  - 「攒着的天：3 / 3」
- 没新事时不弹卡片，照旧显示「上回你走到河埠」这类继续原来那件事的提示（如果现在有的话）。
- 摘要从家里的事件记录生成；看过以后只记「看到哪了」，**重新打开能再看，但不会再扣钱**。
- 卡片要短：390 × 844 一屏放得下，320 × 640 不出现横向滚动。

### 5. 没有攒天时能看的东西

- 现在攒天用完时，院子里只剩「天亮」这一个入口。按 D4 改：能打开战报、摘要、家人和祠堂、院子来看；买卖、修院子、存钱、出门、过夜的按钮灰掉，各写一句「明天才能……」。

## 验收

**单元测试**（进 `npm test`）：
- 把握：门更好 / 机关更多 → 更高；天数更往后 → 更低；永远在 5%–95% 之间；上面那张表的四种情况在大约的范围内
- 同一晚、同一个种子，结果一样；刷新不重抽；一晚只结算一次
- 门破了：只扣钱箱的一成、最多 20 文；钱袋、宝物、体力都不变
- 守住：守住的记录加一，因果分是亲手守住的一半；纸钱大约是亲手守的一半，进钱袋（写清楚「一半」怎么算）
- 不在线：连着没来 1 天、3 天、10 天，各自最多丢一次钱；不长年纪、不花攒天；守住的日子给半份因果，没守住不扣（因果分各项原有的上限照旧）
- 第一世保护：第一世不在线、交给机关守都不丢钱（门破了战报照写）；第二世起照常丢
- 打到一半离开：当天回来接着打；隔天回来按交给机关守结算
- 摘要：只列真的发生的事；看两次不会扣两次

**浏览器测试**：
- 天黑时出现两个选择，按钮上写着把握；带路的第 1 晚也有这两个选择
- 交给机关守一晚：守住、没守住各走一遍，战报和钱箱数字对得上
- 改设备日期模拟离开 3 天：回来先看到摘要卡片，钱箱只少一次
- 攒天用完时能看战报、家人、祠堂、院子；买卖、修院子、存钱、出门都灰掉
- 修院子的按钮上写着把握的变化
- 两种屏幕尺寸截图，没有横向滚动、没有控制台报错

**照旧全绿**：`npm run typecheck`、`npm test`、`npm run build:loop -- --check`、`npm run sync:draw -- --check`、`npm run test:proto`；`npm run balance:night -- --compare-core` 还要逐局对得上（亲手守的难度这次不改）。
