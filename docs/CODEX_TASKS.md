## 任务 1：样机两处小修（`docs/proto/loop/index.html`）

**1a. 门口的鬼图标别叠在一起。**
现在鬼挤在门口时，头上的特点图标（飞、隐、甲）和血条叠成一团，看不清。
- 做法自选：门口的鬼图标自动错开，或者同一种特点合并成「飞 ×3」。
- 验收：门口同时有 6 个鬼时截图，图标都能看清；`npm run test:proto` 全绿。

**1b. 投胎时可以挑去哪个后人家。**
现在有好几个后人时，「回自己家」默认去第一个后人家。
- 改成：每个后人一个选项（「做 XX 的孩子」，最多列 3 个），再加上按因果分给的别人家。
- 验收：在 `scripts/proto-tests/loop-family.test.cjs` 加用例（两个后人时出现两个回自家选项，选第二个后，爹娘写的是第二个后人）；`npm run test:proto` 全绿。

## 任务 2：把「一日一夜」的规则搬进 `src/core`（大活，分步做）

现在样机的规则写在页面脚本里，没有单元测试。要搬进规则核心，以后原样放进 Cocos。

**范围**（对照样机里的函数，见 `docs/HANDOFF.md` 第 2 节的表）：

1. 时间和野外：时辰、三圈地图、采集、遇险（打 / 跑）、天黑、倒下的规则
2. 院子：卖货、换门、机关
3. 守夜：5 波、特点、手里的东西、本事、门、弩机、驰援、家人帮手
4. 家：红线、生孩子、收徒、品级
5. 死后：护家神、当厉鬼
6. 投胎：因果分、三户人家、回自己家、祠堂

**要求**：
- 放在新目录 `src/core/loop/`，**旧的 `src/core` 文件先不动**
- 纯 TypeScript，确定性：随机只走注入的随机数（参考旧的 `world.rng`），不用 `Math.random`、`Date`、DOM
- 所有数字放进一个配置对象，和样机里的 `CFG`、`NIGHT`、`PERKS` 等对应，数值先照抄样机
- 守夜做成固定步长的模拟：`nightStep(state, dt)`；玩家操作是动作（点某个鬼、换手里的东西、挑本事、喊人帮忙）
- 每个阶段做完就配单元测试；`docs/HANDOFF.md` 第 3 节的每条规则至少一个测试
- 守夜难度用测试复现：写一个无界面的机器人（按特点换东西、每秒 3 或 4 下），跑出 `docs/HANDOFF.md` 第 4 节那张表，结果在合理误差内

**分步汇报**：先交 1、3（野外和守夜）及测试，确认后再做其余的。

**之后**（等确认再做）：用 esbuild 把规则核心打进一个新的网页壳（例如 `src/web-loop/`），画面沿用样机的画法，`npm run test:proto` 改成测这个打包出来的页面。旧的 `src/web` 不动。
