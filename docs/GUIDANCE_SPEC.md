> 2026-11-20。产品负责人确认：**先做带路，再做经营**。

## 要解决的问题

样机里每样东西单独看都有意思，但第一天就摆着三圈地图、线索、结伴、场面选择、集市、修院子、交情、家、本事、攒天……**新玩家不知道先做哪个。**

我们的原则是「目标定死，方法放开」。现在方法放开了，**目标没定死**：玩家看不到「我现在该干嘛」。

## 1. 「今天的念头」：随时有一个小目标

- 屏幕顶上一直挂着**一句**小目标，由眼前的情况自然冒出来，例如：
  - 「门太破了，攒 40 文换扇木门」（钱不够换门时）
  - 「娘咳嗽了，去河边采点草药」（家里有人需要时）
  - 「周伯说山那边有好木头」（帮过周伯以后）
  - 「天快黑了，该回家了」（离天黑不到 1 个时辰、人在外面时）
- **只是建议，不是任务**：不理它也没关系，没有惩罚；做完了有一点小反馈（一句话、一个音效位置先留着），然后冒下一个
- 念头要看情况挑最合适的一条，不要一次挂好几条
- 点一下念头，能看到「为什么」（一句话），例如「门血只有 140，第 3 天的鬼会更多」
- 先写 10–15 条念头，覆盖第 1–3 天；汇报里列一张表：什么情况下出现、怎么算做完

## 2. 一天一天开放

| 第几天 | 开放什么 |
| --- | --- |
| 第 1 天 | 家门口、河边一小片、集市；修院子只有换门；晚上守门只有剑 |
| 第 2 天 | 大地图（近郊、山林）、线索、结伴；弓和灯；机关 |
| 第 3 天 | 长大了：结缘、收徒、家和祠堂；禁地 |
| 之后 | 现在已有的其余东西 |

- 没开放的东西**不显示**，不要灰着摆在那里
- 每样新东西第一次出现时，**只用一句话介绍**（由祖宗说，见第 3 条）
- 守夜每波挑本事照旧从第一晚开始（这是最好玩的一刻，不要藏）
- 「设置」里加试玩开关「全部开放（试玩用）」，默认关；浏览器测试里可以打开

## 3. 祖宗带路

- 带路的是**祠堂里的一位祖宗**：一个飘着的老鬼（用捏人台的画法，按鬼的样子画），不是弹窗教程
- 他只在这些时候出现，说**一句话**，几秒后淡出：
  - 新东西第一次开放时
  - 玩家**发呆太久**（例如 20 秒没做任何事）时，提一下当前的念头
  - 天快黑了人还在外面时：「天快黑了，还不回家？」
- 每句话说过就记在存档里，同一句不重复说；玩家可以在「设置」里关掉祖宗带路
- 第一次打开游戏的介绍弹窗，改成祖宗出来说两三句

## 4. 主页按钮减少

- 院子主页现在按钮太多（出门、集市、修院子、家和祠堂、邻居和交情、疗伤、歇到天黑）。按第 2 条，**没开放的不显示**
- 和「今天的念头」相关的那个按钮，稍微醒目一点
