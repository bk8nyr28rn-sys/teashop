# 河边一小片：能走动、能动手的白天（给 Codex 的试验规格）

> 2026-11-19。来源：Codex 上一轮的建议，产品负责人已确认「先做一小块试」。
> 在最新的样机上做（`docs/proto/loop/index.html`，改完跑 `npm run sync:draw` 同步离线版）。做完停下来汇报。
> 两把尺子不变：**玩家觉得爽；自由度尽可能高（目标定死，方法放开）**。

## 要验证的一件事

玩家带着模糊的打算出门，**会不会因为看见了什么、碰上了谁、突然想试个办法，过出跟原计划不一样的一天**。

这是试验，不是正式改版：只做第一天上半天、一小片地方。效果好再往外扩，不好就停。

## 1. 范围：一小片能走动的地方

- 家门口 → 河埠（河边码头）→ 集市口，连成一小片，**点哪走到哪**（单手能玩）
- 镜头和视角你定，要求是手机竖屏上一眼看得清
- 这片地方的边上有一条「往远处走」的路，走过去就回到现在的三圈地图（山林、禁地照旧）
- 第一天出门先进这片地方；第二天起也能进，不强制
- 时间照旧花时辰：走路、动手都花时辰，**河水随时间慢慢涨**（这是这片地方的压力来源）

## 2. 三个动作，五样东西

**动作**（只做三个）：
1. **搬**：拿起、放下
2. **用绳子**：系住、拉、递给别人
3. **招呼**：叫住路过的人

**东西**（只做五样）：漂在岸边的木头（两三根）、一根绳子、岸边的药草、一个挑担子路过的人、一块好看的石头

**每一种搭配都要有看得见的反应**，至少做到下面这些：

| 怎么搭配 | 会发生什么 |
| --- | --- |
| 绳子 + 木头 | 绑成木排；**回家可以坐木排走近路**，省时辰 |
| 搬木头 | 带回家当柴卖钱；或者搭在水沟上当桥 |
| 绳子 + 挑担子的人（他的货卡在河边） | 帮他拉上来；**下午在集市碰见他，他认得你**，给你便宜价或者一条线索 |
| 招呼挑担子的人 | 他帮你搬重东西；或者聊两句，告诉你今天哪里有好东西 |
| 搬石头回家 | 自己挑位置摆在院子里；**晚上守夜时，它在灯下还看得见** |
| 采药草 | 和现在一样，进背包 |

- **同一个目标至少有两种办法**，例如回家：走路 / 坐木排 / 走自己搭的桥
- 河水涨到一定程度，原来能走的岸边会被淹，有的办法就用不了了：逼玩家做选择，但不能逼死（总有一条路能回家）
- **做过的事要留下来**：木排、桥、摆在院里的石头第二天还在；帮过的人记得你

## 3. 画面：不用读字就想走过去

- 照路线图的美术方向画这一小片：白天暖色的江南水乡，参考图里的水道、乌篷船、临水老房子
- 一眼能看出：**水在涨**、**木排能踩**、**那是刚才见过的人**、**院子里那块石头是我带回来的**
- 能互动的东西要比背景醒目，但不要贴满文字说明
- 人物用捏人台画的样子（主角和路人都是）

## 4. 试玩记录（给产品负责人找朋友试玩用）

- 「设置」里加一个「复制试玩记录」：记下这次玩的时候，玩家试了哪些搭配、按什么顺序、在每样东西旁边待了多久、什么时候决定回家
- 产品负责人会找几个第一次玩的人，用**同一个开局**各玩十分钟，再把记录发回来
