# 白天改版：攒天、每个地方不一样、到了有得选（给 Codex 的规格）

> 2026-11-19。来源：Codex 上一轮的试玩意见（模板一、模板二），产品负责人已确认。
> 在 Codex 手里最新的样机上改（`docs/proto/loop/index.html`，改完跑 `npm run sync:draw` 同步离线版）。做完停下来汇报。
> 原则还是两把尺子：**玩家觉得爽；自由度尽可能高（目标定死，方法放开）**。每个选项都要有被选的理由。

## 1. 攒天（产品负责人选的方案 A）

**为什么**：玩得上头时不该被拦住；但孩子是别的真人玩家，一辈子不能一晚上过完，不然一家人碰不上面。

**规则**：
- 每个现实日（本地时间 0 点）给 1 天；没用完的天攒起来，**最多攒 3 天**
- **新玩家开局就有 3 天**，第一次上线能连着玩
- 天亮（开始新的一天）时用掉 1 天；守夜算在当天里，不另外花
- 攒的天用完了：守完夜后不进第二天，显示「今天的日子过完了」，写明下一天什么时候到（还有几小时几分），和现在攒了几天（例如「0 / 3」）
- 顶栏显示「攒着的天：2 / 3」
- 「设置」里加一个试玩开关「不限天数（试玩用）」，默认关；浏览器测试里打开它，免得测试被卡住
- 记在存档里：攒了几天、上次发天的日期；改了存档结构就把版本号加一，旧存档要能读（缺的字段按新玩家给 3 天）

**验收**：用测试改系统时间（或注入「今天的日期」）验证：开局 3 天；用完后被拦；过一个 0 点 +1；连着几天不玩最多攒到 3；打开试玩开关后不拦。

## 2. 每个地方不一样，地图上有当天的线索

**现在的问题**：同一圈的地点（河边、竹林、菜地）路程一样、掉的东西一样，玩家说不出「今天为什么去竹林」。

**改成**：
- **每个地点有自己的特产**（同一圈里也不一样），例如：河边多草药、竹林多柴、菜地最稳；松林多兽皮、猎场兽皮多但野兽也多、矿洞出铁矿；古墓多古物、乱葬岗宝物多但最凶。数值自己定，汇报里列一张表
- **每天每个地点随机一条线索**，地图上点地点时就能看到，例如：
  - 「河边：昨夜涨水，冲下来好多草药」（今天草药多）
  - 「矿洞：洞口有新鲜爪印」（今天兽皮也多，但更危险）
  - 「古墓：有人刚来过，门口掉了半张地图」（今天离宝物更近，也可能被别人捷足先登）
- **线索是提示，不是答案**：会提高某种东西的机会，或者提高危险，但不保证。不能让玩家第二天起只剩背答案

## 3. 到了地方有选择（不只点一个「采集」）

学守夜挑本事的做法：**到了地方，出一个小场面，给 2–3 个选择**。每个选项写清楚：花多少时辰、大概收获、危险高低（低 / 中 / 高）。例如矿洞：

| 选项 | 花多久 | 收获 | 危险 |
| --- | --- | --- | --- |
| 在洞口捡碎矿 | 少 | 铁矿 1 | 低 |
| 往深处找富矿 | 多 | 铁矿 2–3 | 中，可能碰上爪印的主人 |
| 记下线索，明天带人来 | 少 | 今天没有；明天和人结伴来，这里收获翻倍 | 无 |

- 每个地点至少一个自己的小场面，三个选项都要有人愿意选（稳、贪、留后手）
- 当天线索会改变选项（例如涨水时多一个「沿河捞东西」）
- 原来的「遇险：打 / 跑」照旧，从场面里的危险触发
- 采过的地方当天再来，收获变少（免得一直刷一个点）

## 4. 一个人去也要有好处

**现在的问题**：结伴只有好处，一个人去没有理由。

**改成**：
- **结伴**：更安全、多背 3 件、倒下有人扛你回家、交情 +5；但**收获要分给伙伴**（例如每次三成）
- **一个人**：东西全归自己；**走得快**（例如路程少两成）；有些场面选项**只有一个人时才有**，例如「悄悄摸进去」
- 选结伴的弹窗里，两边的好处并排写清楚

## 5. 集市一件一件卖

- 每种货一行：「卖 1 件」「全卖」，保留一个「货全卖了」的快捷按钮
- 宝物照旧一件件卖
