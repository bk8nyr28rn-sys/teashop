# 红线守宅 · 美术设计规格（竖屏 · Q 版修仙）

> 版本：2026-11-15 · 对应代码：`src/web/`（原型）与 `src/core/`（规则）
> 现在画面里的角色、鬼、场景、图标**全部是用代码画的占位图**。本文件告诉美术和工程：要画什么、画成多大、分几层、叫什么名字、怎么动、放在哪里。
> 参考截图在 `docs/art/screens/`（390×844 逻辑像素，@2x 导出）。

---

## 0. 三条总原则

1. **始终以玩得爽为目的**。赢了、升级了、族人诞生了、突破了，都要有又大又快的视觉反馈（见第 7 节）。玩家看到的每一屏都要有“下一步做什么”的提示。
2. **Q 版修仙小院为主体**。可爱、圆润、夜色暖光。不要恐怖：鬼是“萌鬼”，被打散时像泡泡一样“噗”地消失。
3. **角色形象里完全没有戏曲元素**。当家人、搭档、族人、嫡传、NPC、鬼，都按纯 Q 版修仙来画：没有行当、戏曲头饰、水袖、戏妆、脸谱。
4. **戏曲只做很轻的点缀**，只出现在下面两处文字和音效里，不进入任何形象（不要扩大范围）：
   - 鬼敲门的“**咚…咚咚…**”气泡
   - 喜事贺词：嫡传降生、渡劫成功、金缕时，见闻里有一句贺戏的说法

不要画：戏台幕布、戏台框、锣鼓道具、戏服、水袖、翎子、凤冠、脸谱、戏妆、现成剧照或演员形象、粤剧祖师或神明。

## 4. 角色（Q 版当家人 / 族人 / 嫡传 / 搭档）

### 4.1 比例与画板

- 全身画板 **120 × 150**，头身比约 1 : 1（头占上半），脚底投影椭圆在 y = 144
- 头像画板：从全身图里裁 **x 14–106, y 0–92**（正方形，只要头）
- 族人比玩家小：族人约 0.6×，嫡传约 1.0×，玩家在场景里约 76 × 95

### 4.3 可选项（玩家捏形象时）

| 项目 | 选项（名称 · 色值） |
| --- | --- |
| 服装 | **玩家自选风格**：仙袍 `robe`（广袖长袍 + V 领 + 腰带）· 短褂 `tunic`（交领短褂 + 白色小点纹 + 长裤布鞋）· 卫衣 `hoodie`（连帽卫衣 + 帽绳 + 运动鞋）。衣色、镶边在三种服装上都生效；画风不定死，三种要能在同一个院子里站在一起不违和 |
| 发型 | 发髻 `bun`（发包 + 发簪，发簪用镶边色）· 玉冠 `guan`（小发冠用镶边色 + 一颗 `#7FE0FF` 宝石 + 横簪）· 披发 `plain` · 双髻 `twin`（左右两个发包 + 镶边色发绳）· 仙带 `ribbon`（额前一条镶边色发带，脑后两条飘带） |
| 衣色 | 朱红 `#F0525A` · 翠青 `#52D6A6` · 天蓝 `#7FA8FF` · 藤紫 `#9B8CFF` · 明黄 `#FFC24B` · 橘橙 `#FF9A6B` · 桃粉 `#FF8FC7` · 月白 `#E9ECFF` |
| 镶边 | 金 `#FFC24B` · 银 `#E9ECFF` · 玉 `#52D6A6` · 朱 `#F0525A` |
| 肤色 | 白皙 `#FFE4D6` · 暖米 `#F6CFB4` · 蜜色 `#D9A27E` · 栗色 `#A8754F` |
| 发色 | 墨黑 `#2B2233` · 深棕 `#5A3A2E` · 霜银 `#9A9DB8` · 赭红 `#B4432F` |
| 性别 | 女 / 男 / 其他 / 不说。**和发型、道途、衣服都不挂钩**，任何组合都可以 |

> 着色方案：可着色层画成**白色到灰色的灰度图**，引擎里乘以选中的色值。这样 8 × 4 × 4 × 4 种组合只要一套图。

### 4.4 表情（4 种，全身和头像通用）

| 表情 | 眼 | 眉 | 嘴 | 用在哪 |
| --- | --- | --- | --- | --- |
| 平静 `calm` | 圆点 | 无 | 小弧 | 默认 |
| 开心 `happy` | 弯弯眼 | 无 | 张开的笑 | 搭档发来消息、打赢、预览形象 |
| 难过 `sad` | 圆点 | 无 | 倒弧 + 泪滴 | 门被砸破、冷落太久、族人疗伤 |
| 生气 `angry` | 圆点 | 八字眉 | 一字嘴 | 吵架时、渡劫时、打鬼时 |

### 4.5 族人和嫡传的长相（规则，美术照此出变体）

- **族人**：衣色 = 搭档的衣色，镶边 = 玩家的衣色；发型在“披发 / 发髻”间交替；肤色、发色在父母之间交替。孩子看起来像“两个人的结晶”。疗伤中的族人半透明（55%–60%）并且难过表情
- **嫡传**：衣色固定明黄 `#FFC24B`，镶边 = 搭档衣色，玉冠，肤色随玩家、发色随搭档
- **NPC 散修**：按名字固定生成一套（只用发髻 / 玉冠 / 披发），同一个名字永远长一样

## 5. 鬼

画板 **120 × 120**，圆头 + 波浪下摆 + 两只小手，大眼睛、腮红、小圆嘴。**萌，不吓人。**

| 种类 | 文件名 | 身体色 | 特征 | 出现在 |
| --- | --- | --- | --- | --- |
| 野鬼 | `ghost_wild` | 月白 `#E9ECFF` | 没有眉，表情无辜 | 随机砸门、练手小鬼、渡劫大鬼（放大到 120–140） |
| 怨灵 | `ghost_spirit` | 藤紫 `#9B8CFF` | 八字眉 + 下摆拖着 3 根红色怨丝（`#F0525A`，弯曲） | 怨丝凝成的鬼、情敌带来的外来怨灵 |
| 护宅怨灵 | 复用 `ghost_spirit` | 同上，85% 透明 | 缩小到约 38，在门边上下漂浮 | 被感化后留下帮忙守门时 |

每种鬼需要的状态帧（给动画用，可以是单图 + 引擎补间）：待机（漂浮）、靠近、被打散（膨胀消失）、被感化（缩小飘走）、撞门（向前冲）。

渡劫大鬼旁边有一块标签“大鬼 · 战力 N”（`panel` 底、月白描边）。

## 6. 场景

### 6.1 家族大院地图（主场景，画板 390 × 430，等比缩放）

首页就是一张“活的地图”：俯视略带透视的家族大院，鬼在院外游荡、挑门来砸。参考的是“鬼到处飘、砸门”的玩法类型，**布局和画面是自己的，不照搬任何现成游戏的地图**。截图见 `docs/art/screens/02-home.png`、`08-knock-steps.png`。

从后到前分层（括号是原型里的大致位置）：

1. **天空条**（y 0–104）：按时辰换色；左上月亮或太阳，夜里闪烁的星；一层远山剪影
2. **院外地面**：比院子暗一档，鬼在这里游荡
3. **院墙**（x 26–364，y 118–416，圆角 16）：藤紫粗墙；**三个院门**（左、右、下各一个，金色门柱），鬼从这里进；四角各一个**阵眼**（发光圆点，颜色跟大阵状态走：正常金、受损橙、受保护青）
4. **院子地面**：地砖网格 + 从正门通向下院门的一条石板路。受保护（新手期 / 闭关 / 劫后余生）时，院墙外圈罩一层青色光
5. **你的宅子**（正中，x 110–280，y 104–240）：紫色大屋顶 + 金色翘角；牌匾写“{名字}宅”；**门上方一条血条**（符阵等级减受损，颜色同阵眼）+“大阵 数值”；拱形红门，受损时门上有裂纹；闭关时贴黄符；两盏灯笼
6. **护宅大阵光圈**：以门为中心的扁椭圆（半径 104 × 20），虚线顺着流动
7. **灵石堆**（左，约 80, 214）：按可收数量 1–3 颗，上方绿色“+N”气泡上下轻跳；**点了直接收**
8. **丹炉**（右，约 312, 196）：三足炉 + 炉火呼吸 + 冒烟；右上角紫色圆标写诡心数；**点了打开炼丹**
9. **族人小屋**（6 块地：左右两列各 2 + 底下 2）：小白墙、紫屋顶、红门、亮灯的小窗；族人站在屋旁。没人住的地画虚线框写“空地”。疗伤中的族人半透明 + 白底红十字。超过 6 位时底部写“还有 N 位族人在后院”
10. **隔壁：搭档的宅子**（右上，院墙外）：真人搭档绿屋顶、NPC 灰紫屋顶；下面胶囊写“{名字}家 · 关系等级”；搭档在线时站在门口、窗亮；捎话来时头上冒“…”气泡；吵架时冒火星。**红线从隔壁门口拉到你家门口**（正常 `red`、吵架 `ember` 虚线、金缕 `gold`）。没有线时隔壁是虚线框“隔壁空着 · 去牵红线”
11. **玩家角色**：站在门左边（约 46 × 58），可点，打开捏形象
12. **游荡的鬼**（循环）：院外固定 2 只野鬼沿上边、左边慢慢飘；有怨丝时多 1–3 只怨灵（右边、下边、上边）；**不受保护时院子里还有 1 只在族人小屋之间晃**（怨气深重时换成怨灵）

### 6.1.1 鬼来砸门（地图上的一次性演出）

见 7.2。鬼从三个院门里随机一个进来，砸的永远是正中你家的门。

### 6.2 渡劫场景（画板 390 × 240）

深夜底 `#191B40`；左右两道金色闪电（每 2.8 秒闪一下）；中间上方野鬼大鬼（120）漂浮；下方莲台（两层粉红椭圆 + 花瓣）；玩家站在莲台上（生气表情），护法搭档在左边半透明。

### 6.3 结伴历练（弹层里的小舞台）

圆角 20 的深色径向渐变底，玩家和搭档并排站（各 84 × 105）。成功时两人跳两下；结果盖一层半透明，大字“满载而归！”（金）或“铩羽而归…”（橙）。

## 7. 动效与“爽点”反馈（最重要的一节）

### 7.1 常驻动画（循环，所有循环动画共享同一个时间起点，重绘时不能跳帧）

| 名称 | 对象 | 参数 |
| --- | --- | --- |
| bob | 玩家角色、灵石堆、渡劫时的玩家 | 2.6 秒，上下 3 像素，缓入缓出 |
| float | 鬼、护宅怨灵 | 3.2 秒，上下 7 像素 |
| ward-flow | 护宅大阵光圈 | 3 秒，虚线沿椭圆流动 |
| roam | 游荡的鬼 | 16–26 秒一圈，匀速，沿院墙外或院内路线往返 |
| glow | 灯笼、星星 | 2.6 秒，透明度 1 → 0.65 |
| drift | 云 | 40 秒，往返平移 26 像素 |
| pulse | 红线 | 2.2 秒，线宽 3 → 4.5 |
| bolt | 渡劫闪电 | 2.8 秒一周期，88%–94% 处闪两下 |

### 7.2 鬼来砸门（一次性，总长 4.8 秒）

| 时间 | 动作 |
| --- | --- |
| 0 – 1.5 秒 | 鬼从左 / 右 / 下院门之一飘进来，拐一下，停在门口 |
| 0.4 – 2.8 秒 | 屏幕上方提示“戳戳它，出口气！”（不能写“帮忙打”之类暗示能改结果的话） |
| 1.5 – 2.6 秒 | 砸三下：鬼往门上撞（放大 1.1–1.2 倍），每撞一下门口扩散一圈白色冲击环；白色气泡“咚…咚咚…” |
| 任何时候 | **玩家点鬼**：点击处冒金色星星 + “啪！ / 砰！ / 去！ / 嘿！”，鬼左右晃一下。**只是手感，不改结果**（结果由规则决定，改成“点了有用”需要先定规则） |

### 7.3 中央弹字（爽点的主力）

## 11. 文案语气

- 叙述统一用“搭档”“TA”等中性词，不写生育，任何组合都成立（见 v2.1 方案）
- 系统提示简短、口语、带一点修仙味（“打坐”“灵石”“历练”），不要满屏戏文腔
- 失败提示说清楚原因和怎么办（例：“灵石不够（至少 20）”“修为还没攒满”）
- 名字是玩家输入的，联网后别人看得到，上线前要接敏感词审核
