# 敏感说法表

> 2026-11-24 · 产品负责人定了：先不砍「老死后当一晚鬼」，但要留好退路（见 `docs/ROADMAP.md`「1️⃣ 审核」的讨论）。
> 退路有两条：**一个开关**（关掉当鬼那一晚），和**这张表**（一键换掉敏感的词）。

## 1. 开关：老死后直接下一世

- **产品开关**：`src/core/loop/rebirth.ts` 里的 `AFTERLIFE.night`。改成 `false` 再跑 `npm run build:loop`，所有人老死后都不当鬼，直接去奈何桥（或换词以后的「渡口」）选人家
- **试玩开关**：样机「设置」里的「老死后直接下一世，不当鬼（试玩用）」，只影响自己这个存档，跨世保留
- 关掉以后：没有护家神、没有当厉鬼，因果分里也不会有这两项；其余（祠堂画像、投胎、回自己家）照旧

## 2. 敏感的词

审核时可能被问到的说法。数字是 2026-11-24 在玩家看得到的文件里出现的次数（`node scripts/terms.mjs` 能随时重新数）。

| 词 | 用在哪 | 次数 | 备选说法（举例，没定） |
| --- | --- | --- | --- |
| 鬼 | 夜里来砸门的、守夜、机关说明、老死后的样子 | 约 90 | 夜祟、邪祟 |
| 厉鬼 | 老死后去砸别人家门、真人精英 | 10 | 凶祟 |
| 护家神 | 老死后回自家守一夜 | 7 | 守宅灵 |
| 阴间 | 当鬼时顶上的名字 | 4 | 幽夜 |
| 奈何桥 | 选下一户人家的地方 | 9 | 渡口 |
| 投胎 | 选人家、回自己家 | 20 | 转世 |
| 魂火 | 当厉鬼时的命 | 4 | 灵火 |
| 葫芦 | 当厉鬼被捉 | 5 | （可以不换） |
| 显灵 | 护家神那一晚 | 4 | 现身 |
| 下一世、前世 | 很多地方 | 约 17 | （一般不用换） |

## 3. 怎么换

```bash
node scripts/terms.mjs                               # 看每个词在哪些文件里出现几次
node scripts/terms.mjs --apply docs/terms-alt.json   # 照表换掉，并重新打包样机
```

- 换词表是一个 JSON：左边是现在的词，右边是换成什么（`docs/terms-alt.json` 是一个例子）
- 长词先换：「厉鬼」会整个换成「凶祟」，不会变成「厉夜祟」
- 只换玩家看得到的文字（样机页面、`assets/` 里的脚本、`src/core/loop/` 里的说明文字），不碰换行符
- 换完以后，测试里写死的旧说法要跟着改（例如「当护家神」）
- `scripts/proto-tests/terms.test.cjs` 会在一份临时拷贝上真的换一遍，再打开样机玩到投胎，确认换完还能玩
