# teashop · 融合玩法逻辑核心

《融合玩法方案汇总（v2.1）》的规则实现、数值模拟器和竖屏网页可玩原型。

**接手调试先读 [`docs/HANDOFF.md`](docs/HANDOFF.md)**；美术规格见 [`docs/ART_SPEC.md`](docs/ART_SPEC.md)；方案文档离线副本见 [`docs/DESIGN_v2.1.md`](docs/DESIGN_v2.1.md)；各页面参考截图在 `docs/art/screens/`。

## 目录

```
src/core/   逻辑核心：只有规则，不依赖任何引擎和 Node API，可以原样放进 Cocos Creator
  config.ts   所有可调数值（对应文档的“待定数值”表），默认值只是占位
  world.ts    世界、家族、时间、闭关
  threads.ts  红线：牵线、互动、剪线、复合、拉黑、冷落、多对象、情丝去向
  grudge.ts   怨丝池和每日上限
  defense.ts  守宅：两种鬼、砸门、感化、失败惩罚、劫后余生、阵法、炼丹、渡劫
  family.ts   族人和嫡传
  rivals.ts   NPC 情敌和真人抢亲
  tick.ts     每小时推进一次
src/sim/    数值模拟器（只在开发时用，不进游戏）
src/web/    网页可玩原型：界面只是一层壳，规则全部来自 src/core
test/       单元测试，每条决定至少一个
docs/       交接说明、美术规格、方案文档副本、参考截图
design/     竖屏设计稿画布源文件
```

代码注释里的 `#N` 对应 v2 文档“决定记录”的编号。

## 命令

```bash
npm install
npm test            # 单元测试
npm run typecheck   # 类型检查（核心用不含 Node 的配置单独检查）
npm run sim         # 数值模拟：6 类玩家，每类 200 人，30 天
npm run sim -- --players 500 --days 60 --seed 3
npm run sim -- --set grudge.dailyCap=20 --set breach.graceActions=8
npm run sim -- --json
npm run build:web   # 打包网页原型：dist/web/teashop.html（单文件，可直接用浏览器打开）
```

## 网页原型（竖屏）

用来先验证“好不好玩”，再投入做 Cocos 界面。打包出来是一个独立的 HTML 文件，手机浏览器直接能玩。

字体已按界面实际用字裁剪成 WOFF2 并内嵌到 HTML，断网也可显示站酷快乐体与思源黑体。新增用字后需要刷新字体子集；来源、授权及刷新步骤见 `assets/fonts/README.md`。正常网页构建不需要网络或 Python。

- **画面**：Q 版修仙小院为主（夜色、远山、护宅大阵），角色和鬼都是用代码画的占位，正式美术照同样的比例替换。角色形象里没有戏曲元素；戏曲只在敲门的“咚咚”和喜事贺词里轻轻点一下
- **以爽为先**：打散怨灵、关系升级、族人诞生、突破这些时刻，屏幕中央弹大字和数字；场景里有砸门的小动画
- **首页是家族大院地图**：你家在正中，族人住周围的小屋，搭档住隔壁、两家连着红线；鬼在院外游荡，从三个院门进来砸你家的门，在线时可以点鬼（手感，不改结果）。灵石堆、丹炉直接点
- **捏形象**：名字、性别（随时可改）、服装风格（仙袍 / 短褂 / 卫衣）、发型、衣色、镶边、肤色、发色、道途（身份标签，不影响数值）。存在逻辑核心的 `House.appearance` 里，族人的样子取自父母双方
- **四个页面**：宅院（场景 + 待办 + 常用操作）、红线、家族、渡劫；大互动叫“结伴历练”
- 你是当家人；**阿青**是机器人好友（每天 9、13、21 点上线）；**白露**在你设为“专一”时偶尔来抢亲
- 时间流速：暂停 / 实时 / 快进（1 时辰 = 2 秒）/ 极速（1 时辰 = 0.2 秒）
- 存档在浏览器的 localStorage；重新打开时按离开时的流速补算离线时间（最多 14 天），并弹出“你不在的时候”
- 代码：`art.ts`（画角色和鬼）、`game.ts`（控制层：时间、机器人、存档、弹字）、`ui.ts`（各页面）、`main.ts`（只重画变了的区域）

## 模拟器里的玩家类型

| 类型 | 假设 |
| --- | --- |
| 独自玩 | 只和 NPC 牵线，每天上线两次 |
| 好友一对一 | 两个专一的好友互相牵线，每天上线两次 |
| 忙碌玩家 | 隔天上线一次，每月闭关 5 天 |
| 多对象（高强度） | 一位真人好友 + 第 3、7、12 天各加一位 NPC，每天上线三次 |
| 多对象（同样投入） | 同上，但上线频率和互动意愿和一对一一样，用来做公平对照 |
| 未成年 | 只在周五到周日 20–21 点能玩 |

这些都是粗略的行为假设，要和真实数据对照着改（`src/sim/agents.ts`）。

## 模拟发现的问题

### 已处理

**1. 多对象原本是最强的玩法。** 两个来源：

- 守门和结族人按线数叠加 → 回报递减（第 1 根 100%，第 2 根 50%……）、心力分散、NPC 线也要维护
- 怨丝还原比例大于 1:1，怨丝成了最浓那根线的燃料 → 打散还原 10%–30%，感化还原 50%

**2. 成长太快。** 按“一对认真的好友约 3 个月到金缕”校准。

**3. 忙碌玩家掉队（90 天浓度只有一对一的十分之一）。** 加了两级互动：

- 小互动（了解对方）：随时可做，增长很小（0.5）
- 大互动：押上灵石，随机大成功或大失败；成功的情丝比失败时的损失略多；真人搭档同时在场成功率 +15%
- 灵石按时间累积（离线也在打坐），所以成长主要看时间，不看上线次数

同时加了**关系分级**（相识 → 知己 → 倾心 → 挚爱 → 金缕）和**多对象吃醋**：和一根线互动时，其他线按等级变淡、生怨，掉到区间下限就降级。

### 现在的结果（120 天，默认数值）

| 玩家类型 | 砸破/周 | 单线浓度 | 族人 | 金缕 | 嫡传中位天 |
| --- | --- | --- | --- | --- | --- |
| 好友一对一 | 0.77 | 195 | 10.8 | 100%，第 91.5 天 | 24.9 |
| 忙碌玩家 | 0.67 | 165 | 6.2 | 未达到 | 46.9 |
| 未成年 | 0.14 | 189 | 8.3 | 第 117.8 天 | 34.8 |
| 独自玩（NPC） | 1.00 | 131 | 5.9 | 未达到 | 不适用 |
| 多对象（同样投入） | 1.72 | 34 | 7.2 | 未达到 | 未达到 |

忙碌玩家从“90 天浓度 23”追到了 168。

闭关（包括未成年人的自动闭关）只负责保护，不停止成长：族人照常结。未成年玩家 120 天的族人从 0 个变成 8.7 个。

独自玩（NPC 线）大约 163 天到金缕，比好友一对一慢一倍。原因不是“同时在场”加成，而是真人线有两个人各押各的预算。**决定接受这个差距**：#2 的意思更新为“规则相同，但真人线有两份投入”。需要时可以调 `npc.investMultiplier`（1.8 时约 109 天）。

多对象原本叠了四层惩罚（感情预算被分摊、回报递减、心力分散、吃醋），每一项都比一对一差。预算分摊已经能防止多对象族人太多，所以**回报递减默认关闭**（`thread.diminishing = 1`）。

### 待决定

1. **每日怨丝上限几乎没触发过**（加了争执后每人每天散掉约 0.01）

**争执**：随机误会（刚吃过醋、被冷落过时更容易），或小互动选了冒险说法（增长翻倍，25% 概率引发误会）。争执时 20% 浓度散开，其中一半变成怨丝（两边各生）。双方各上线 3 次之内两人都和好（最多 14 天）：散开的那一半聚回；破镜重圆再把这次的怨丝转化 20% 回红线（30 天冷却，和剪线复合共用）。吵架总会亏一点，和好是止损，所以刷不了。

和好期限原来是 3 天，忙碌玩家的和好率只有 58%；改成按双方上线次数算以后是 96%。界面层在玩家每次上线时调用 `checkIn`。

剪线后复合也改成了同样的规则（原来“复合恢复到 1.2 倍”可以剪了再复合来刷浓度）。

**抢亲**（两种都有）：

- NPC 情敌：每根线每天 4% 概率出现，带来一只外来怨灵（怨丝不进池子）。红线够浓就感化（原文“感情越好，越能化解外人的怨”）；打散则这根线涨情丝；输了这根线变淡，不算砸破。好友一对一约 72% 能感化，多对象几乎感化不了
- 真人抢亲：只能对设了专一、已经有线的人发起；对方同意才成立，旧线按剪线处理，再牵新线。可以拒绝，同一人对同一人 7 天冷却，拉黑后不能发起，陌生人要过等级门槛

**渡劫**：修为进度随打坐积累，攒满后自选时机发起，可以吃破境丹（诡心炼）、叫一位搭档护法。失败按门被砸破处理并冷却 3 天，修为进度保留，当家人不掉境界。现在大约第 33 天到境界 3（陌生人匹配门槛），渡劫成功率约 60%。

**新手期（把爽点提前，`newbie`）**：保护期 3 天里第 20 个时辰来一只必赢的练手小鬼；相识阶段互动和结伴历练的情丝 ×8；前两位族人只要平时的 3% 和 15% 进度。结伴历练的兑换比例相应从 0.05 调到 0.038，保证长期节奏不变。

| 好友一对一（中位天） | 知己 | 第一位族人 | 嫡传 | 金缕 |
| --- | --- | --- | --- | --- |
| 加新手期之前 | 12.5 | 35.8 | 25.9 | 89.5 |
| 加新手期之后 | 1.9 | 2.5 | 15.9 | 90.5 |

“离线期间最多输一次”在所有场景下都成立（#11）。

## 守夜局（实时塔防）

首页“开始守夜”进去：鬼分 5 波从三个院门进来砸你家的门，最后一波有大鬼。孩子站在院子里自动出手（道途决定本事），你自己站在门边也会打；点鬼能打掉血，点孩子花灵气升级，还能修门、加固门。每天前 2 局有奖励（灵石、诡心、上阵孩子的修为），输了不掉东西。规则在 `src/core/raid.ts`，难度用 `npx tsx scripts/raid-balance.ts` 校准。
